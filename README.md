# 🌍 Tell a Climate Story | NASA Space Apps Challenge 2024

A visual storytelling project built to decode and display the realities of greenhouse gas emissions using **NASA-backed open datasets**.  
This dashboard transforms raw GHG data into a clear, interactive climate narrative.  

> 🌱 *Data is powerful — but stories move people.*  
> This project turns climate data into action-inspiring visualizations.

---

## 💡 What’s Inside?

📊 **Dashboard**: Interactive Streamlit-based visual platform that  
 - Shows trends in CO₂ and CH₄ emissions over time  
 - Compares emission patterns by region  
 - Overlays population density and GHG sources  
 - Is intuitive enough for students, citizens, and policymakers alike

🧠 **Core Objective**  
To tell a climate change story backed by data from the **U.S. GHG Center**, and present it in a way that’s both educational and motivating for climate action.

---

## 🛠 Tech Stack

| Category         | Tools Used                                  |
|------------------|----------------------------------------------|
| Languages        | Python                                       |
| Visualization    | Plotly, Seaborn, Pandas, Matplotlib          |
| App Framework    | Streamlit                                    |
| Datasets         | U.S. GHG Center (NASA, EPA), Population data |
| APIs             | GHG Center API, Open Data APIs               |

---

## 🌐 Key Features

✅ **Dynamic Charts**: CO₂ and CH₄ plotted across years & locations  
✅ **Region Selector**: Focus on specific countries or global view  
✅ **Population vs Emission View**: Identify high-emission/high-pop regions  
✅ **Clean UI**: Easy for non-experts to interact and learn

---

## 🚀 How to Run Locally

``bash
git clone https://github.com/Webwavercode/Tell-a-climate-story
cd Tell-a-climate-story
pip install -r requirements.txt
streamlit run app.py
Make sure Python 3.8+ is installed and working.
